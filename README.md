# NEXORA Business Management

NEXORA is a business management web application built using Python and the **NiceGUI** framework. It provides a clean interface to manage daily business operations, track tasks, and streamline workflows.

## Features
* Modern and responsive web interface
* User authentication and login system
* Real-time task management and overview tracking
* Lightweight built-in SQLite database integration

## Tech Stack
* **Language:** Python
* **Framework:** NiceGUI
* **Database:** SQLite3
